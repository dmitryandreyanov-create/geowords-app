# Независимая проверка географических подсказок

`engine/spatial-semantics.js` — чистый резолвер, не второй генератор. Пока не подключён ни к игровому приложению, ни к runtime-Curriculum и не включён в Pages. Прежний пилот Rivers и Mountains не менялись.

## Принцип

На входе структурированный запрос и **полный набор букв конкретного задания**, с отдельными проверенными географическими принадлежностями каждой буквы. На выходе — `unique`, `ambiguous`, `no_match` либо `blocked` с причиной. Буква, ответ, порядковый номер и назначенный пользователем маркер не участвуют в вычислении совпадений. `resolvesTo` из выбранного ответа не создаётся.

Поддерживаются шесть типов: объект (`place`), часть объекта (`region`), сторона океана (`side`), между двумя объектами (`between`), два полушария (`hemisphere`) и экватор (`boundary`). Список стран/островов и прямоугольные географические эвристики не подставляются. Принадлежности должны быть явно проверены по авторской карте; для Евразии необходимо записывать перекрывающиеся принадлежности Европы и Азии. Резолвер не делает вывод о географии по ID.

Для L1 все 63 исходные формулировки получили `candidateQuery`, включая предлагаемые зависимости от ранее изученных фактов. Тип запроса — техническая модель, а предложенные целевые объекты и факты остаются `editorial_pending`.

## Защита от ложной однозначности

- Неутверждённый запрос или неизученные факты/объекты блокируют вычисление.
- Карта содержит SHA-256 исходного изображения и канонический список ID всех букв задания. Удаление «неудобной» буквы из входа блокирует проверку, а не делает ответ единственным. Вызывающая сторона должна передавать доверенный полный scope задания, не составлять его из уже найденного ответа.
- Проверка географии нужна **для каждой** буквы, включая потенциальных конкурентов. Отсутствие записи означает «неизвестно», а не «не подходит». Все принадлежности должны быть исчерпывающими: явное `complete: true` — редакторское утверждение полноты, а не автоматически вычисляемый флаг.
- Утверждение связано с картой, её хешем, координатами буквы, концом и началом стрелки. Изменение этих данных делает свидетельство устаревшим.
- `physical` описывает положение центра буквы; `target` — конец стрелки. У буквы без стрелки `target: null`. Поля каналов: `places`, `regions`, `sides`, `between`, `hemispheres`, `boundaries`. Пустые массивы допустимы только после полной редакторской проверки соответствующего канала.
- По умолчанию L1 использует консервативный канал `either`: проверяется как буква, так и конец стрелки. Поэтому буква в Индийском океане, указывающая на остров, тоже конкурирует с океанской подсказкой. Более узкие каналы `physical` и `target` доступны только как явное утверждённое решение.
- Противоречивые полушария и одновременные «на экваторе»/«северное полушарие» блокируются. Широта, долгота и автоматические пороги x/y не используются.

## Настоящие данные пока заблокированы

`data/import-staging/l1-spatial-review-draft.json` — **пустой каркас**, десять map scopes и 97 записей. Хеши и привязки перенесены из исходных файлов; `evidence/physical/target` остаются null, `complete: false`. Никакие принадлежности не выведены из выбранных пользователем ответов. Разметка букв не равна разметке географии.

Даже если в тестовой копии временно разрешить предложенный запрос, все 97 настоящих подсказок остаются `blocked: incomplete_geography`. Таким образом текущий PASS относится к механизму и защитам, а не к правильности авторских карт.

Каркас воспроизводится командой `node tools/build_l1_spatial_review.mjs`; генератор откажется перезаписать заполненные географические решения. Рабочие подтверждения следует сохранять отдельным экспортом, не заменять автоматически исходный пустой шаблон.

Проверка: `node tools/build_l1_catalog.mjs --check && node tools/build_l1_spatial_review.mjs --check && node scripts/validate-spatial-semantics.mjs`.

## Работа в редакторе

При первом открытии редактор берёт уже полученные 69 назначений из `review-assignments.json`. Локальный экспорт v1/v2, если он есть, имеет приоритет; невалидное локальное сохранение не удаляется молча. Повторно назначать уже полученные буквы не нужно.

Ниже основной карты находится панель «География букв · Level 1». Выберите любую букву в отдельном списке, независимо от назначенного ответа. Укажите все применимые объекты, части объектов, стороны океана, отношения «между», полушария и экватор. Набор предлагаемых квалификаторов покрывает запросы текущего L1, не является всеобщим справочником; неизвестные географические ID запрещены.

Для стрелки заполните отдельно «Положение самой буквы» и «Конец стрелки». Подтверждение невозможно, пока оба канала не заполнены. Чтобы намеренно подтвердить пустые списки, выберите соответствующий канал и подтвердите после его проверки — они не подставляются автоматически за неизвестную географию. Галочка полноты требует самостоятельной проверки всех свойств по карте; алгоритм не доказывает полноту за редактора.

Изменение любого свойства снимает утверждение **всей буквы**, сохраняя данные как черновик. Кнопка «Снять утверждение» сохраняет заполненные свойства. География автосохраняется под отдельным ключом `geowords-spatial-review-v1`; экспорт — `geowords-l1-spatial-review.json`. Импорт проверяет исходные хеши, координаты, стрелки и полноту scopes до изменения текущего состояния. Чужой/устаревший файл отклоняется атомарно. При недоступном localStorage появляется предупреждение; JSON можно экспортировать вручную.

Старый экспорт назначений и новый географический экспорт **разные файлы**. Импорт одного не заменяет другой. Подтверждение свойств буквы не создаёт старую отметку подтверждения подсказки и не утверждает candidate-запрос. Level 2 остаётся в прежнем режиме; его пространственные свойства пока не реализованы.

Несовместимая география из localStorage не загружается и защищается от автоматической перезаписи. Кнопка «Скачать несовместимое сохранение» выгружает исходную строку без изменений; новый черновик можно экспортировать отдельно. Защита снимается только после явного импорта совместимого географического файла. Старые данные не удаляются по результату ошибки загрузки.

Отчёт автоматически проверяет каждую подсказку относительно полного набора букв. При неполных записях показывает блокировку и количество неизвестных букв; после полной разметки — совпадения, неоднозначность, отсутствие ответа и несоответствие назначенному маркеру. Это **редакторский preview по предложенным фактам**, не состояние знаний ребёнка, не утверждение уроков и не разрешение выпуска. Технические тесты используют явно синтетические принадлежности, не записывают их в источник.

Воспроизводимая ручная проверка: открыть редактор через локальный HTTP, выбрать букву L1, заполнить положение и явно подтвердить полноту, обновить вкладку, экспортировать JSON. Изменить объект — утверждение должно исчезнуть. Импортировать экспорт — оно восстановится; файл с изменёнными координатами должен быть отвергнут без потери текущих данных. Для буквы со стрелкой проверить невозможность подтверждения без её конца. Старый файл назначений не должен стирать географию. Все исходные карты и их размеры остаются прежними.

Проверки модели: `node scripts/validate-spatial-review.mjs`. Реальные перезагрузка/экспорт/импорт и состояния стрелок проверяются Chromium на 360px в `npm run test:browser`.
