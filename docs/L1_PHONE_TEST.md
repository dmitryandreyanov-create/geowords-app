# Проверка всего L1 на телефоне

По просьбе пользователя от 13 октября 2026 года полный L1 доступен в основном PWA как отдельный взрослый тест. Открыть главную страницу в Safari, выбрать «Continue Level 1 test». Для установки: Share → Add to Home Screen → Add.

Десять авторских заданий идут в исходном порядке; каждое открывает шесть фиксированных практических слов из существующего плана. Всего 70 заданий. Первый комплект сохраняет ровно шесть ранее просмотренных пользователем раскладок. Остальные 54 раскладки — непроверенные кандидаты на основе сохранённых исходных связей подсказок с точками, а не независимое географическое доказательство. Факты и определения остаются pending, approved не добавляется; реальный адаптер Curriculum по-прежнему блокирует выпуск.

Перед авторским заданием читаются его вводные факты, после — следующий авторский блок, затем практика. В подсказках используются только факты, уже показанные к этому моменту. Если текущего набора точек недостаточно для длинного слова, практика использует дополнительные точки уже пройденных заданий на том же исходном bitmap либо ранее показанную авторскую карту. Карты, проценты координат и исходные стрелки не редактируются. Доля нового объекта и педагогическая пригодность этих комбинаций ещё не утверждены.

Неверную букву можно исправить сразу. Правильный частичный ответ сохраняется после каждого нажатия; после reload нужно снова открыть L1. На 7/7 автоматически открывается следующее авторское задание. Повтор слова не добавляет зачёт. Тестовый ключ `geowords_l1_phone_trial_v1` изолирован от Mountains/Rivers и редакторских решений. Кнопка «Save test progress» сохраняет JSON. Сохранение другой версии защищено от перезаписи и экспортируется как исходный backup.

Публикация: workflow Pages допускает push текущей ветки `gpt/unified-geowords-engine` после всех проверок. Это тестовая публикация без merge PR #8; главная страница сохраняет Mountains/Rivers и добавляет отдельную кнопку L1. Исходники публичны. Новый cache service worker включает обе L1 карты и весь пакет для offline.

Ручная проверка: открыть CONTINENT, ошибиться, исправить; перезагрузить с частичным ответом и продолжить. Завершить 1+6, увидеть HEMISPHERE. Повторить слово без роста счёта; закрыть и открыть установленное приложение без сети. При ошибке записать шаг, слово, номер подсказки и прислать снимок карты.

Автоматические проверки: `node scripts/validate-l1-phone.mjs`, `node scripts/build-pages.mjs`, `node scripts/validate-l1-phone-browser.mjs`. Последняя проходит все 70 слов на 360px, проверяет partial reload, неверную букву, replay, zoom, offline reload и переходы 7/7. Географического и педагогического утверждения тесты не заменяют.
