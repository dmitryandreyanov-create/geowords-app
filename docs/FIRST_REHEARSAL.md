# Первый комплект L1 — отдельное пробное прохождение

В едином редакторе `tools/review-import.html` добавлена панель «Пробное прохождение первого комплекта L1» для первых двух исходных заданий. Это не отдельная детская игра и не запуск approved Curriculum. Main, Pages allowlist, исходные карты/размеры/пространство под ними и прочие панели не изменены. Панель использует `engine/geowords.js` для зачёта 1+6; второй генератор не создаётся.

## Область человеческой проверки

13 октября 2026 пользователь подтвердил в чате девять подсказок первого авторского CONTINENT, сохранение авторского порядка объяснений и **шесть конкретных показанных черновиков** ATLAS, GLOBE, MAPPING, REGION, BORDER, SPHERE: расположение букв соответствует, слова собираются. Подтверждение не распространяется на другие будущие варианты, независимую spatial-разметку, педагогическую пригодность определений или точность фактов.

В тот же день пользователь самостоятельно прошёл переносимый GeoWords_L1_Rehearsal.html на ноутбуке Windows и сообщил, что всё хорошо, исправлений нет. Предоставленное фото показывает 7/7, счётчик исправлений 0 и переход к HEMISPHERE. Это подтверждение конкретной пробы на ноутбуке; iPhone/PWA и другие варианты не проверены этим результатом. Пакет и SHA сохранений не меняются из-за этой записи.

После прохождения отдельно подтверждены три отношения первой карты: E — между двумя Америками; N — между Африкой и Евразией; T — между Австралией и Евразией. Для этих точек пользователь выбрал только такие подсказки. Решения сохранены в l1-relation-decisions.json с исходными координатами/SHA карты. Принадлежность континентам остаётся null, не «географически вне континентов». Новые предложения показывают только подтверждённые пары, сохраняют pending/complete false и не заменяют уже сохранённую разметку пользователя. Для неутверждённых физических свойств нельзя считать доказанной однозначность широких материковых подсказок. Полный независимый резолвер и Curriculum остаются заблокированы; эти частичные решения не дают выпуска или новых approved-вариантов.

`data/import-staging/l1-first-rehearsal.json` фиксирует именно показанные раскладки, исходную карту/точки, исходные английские подсказки и определения, source SHA и SHA каждого варианта. Receipt записан как `humanReview` с ограниченными полями, не как глобальное `approved`. Учебные факты скопированы из автора как pending; не считаются утверждёнными из-за пробы. Настоящие geography, lexicon, learning/content-review и curriculum-источники не изменены.

Раскладки ранее получены общим `semantic.generateAnchored` с seed `review-only-l1-01-<wordId>`, на исходных точках карты, с авторскими соответствиями подсказок. Это не независимое доказательство пространственной семантики. В пробе варианты **не регенерируются**: взрослый решает ровно просмотренные раскладки. Изменение алгоритма или данных не переносит человеческое подтверждение на новые варианты автоматически. Валидатор сверяет результат общего sampler и хеши; браузер проверяет receipt перед открытием.

## Пробный маршрут

1. Перед CONTINENT — вводные факты со страницы 6 автора.
2. Авторское слово по девяти исходным подсказкам.
3. После CONTINENT — блок страницы 8 «Для следующего задания нужно знать».
4. Шесть фиксированных практических вариантов по порядку. Их подсказки используют только названия/отношения из уже показанного вводного материала.
5. После 7/7 основной редактор автоматически открывает следующий исходный HEMISPHERE. Это указатель следующего шага; его практика в этой пробе отсутствует и не утверждается. На 6/7 перехода нет.

Выбор букв допускает ошибки. Кнопки «Убрать последнюю букву» и «Очистить текущий ответ» позволяют исправить ответ, не теряя заработанные пробные баллы. Проверяется соответствие ID буквы каждой подсказке, не только строка слова: одинаковые буквы на неправильных точках не засчитываются. Повторного зачёта нет.

Пробный localStorage `geowords-l1-first-rehearsal-v1` хранит только trial_only, пакетный source SHA, просмотренные учебные экраны, пробный прогресс и незавершённый ответ. Это не ученические knownFacts/knownPlaces или настоящий игровой прогресс. Экспорт/импорт имеет отдельный scope. Несовместимый raw JSON не перезаписывается; доступна резервная копия. Ошибка импорта не меняет состояние. Экспортировать можно и при недоступном localStorage.

## Ручная проверка

Открыть единый редактор через локальный HTTP, выбрать L1-01 и прокрутить к пробной панели. Прочитать вводный блок, собрать CONTINENT кликами по буквам и проверить. Прочитать следующий блок автора. Решать практические слова; намеренно ошибиться, исправить, перезагрузить с незавершённым ответом, экспортировать и импортировать прогресс. На 6/7 остаётся последний вариант, на 7/7 открывается HEMISPHERE. Проверить, что остальные редакторские состояния и настоящая детская игра не изменились.

Автопроверки: `node scripts/validate-rehearsal.mjs`, `npm run test:browser`. Полноценный Curriculum остаётся заблокирован до независимой географии, содержательных утверждений и остальных редакторских решений. PR #8 не мержить без согласования.
