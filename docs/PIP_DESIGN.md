# Пип: утверждённый визуальный концепт

## Партия 2 — жесты и портреты

Добавлены `pip-point-right.png`, `pip-wonder.png`, `pip-face-happy.png`, `pip-face-oops.png`, `pip-face-wow.png`: отдельные прозрачные PNG 1024×1024. Всего поставлено 13 из 76 файлов. Все доступны в `/graphics/`, визуальное утверждение по-прежнему ожидает проверки на телефоне. Маленький Пип рядом с подсказкой теперь использует портрет: обычная улыбка, восторг при верном ответе, мягкое смущение при ошибке. Подзорная труба при запросе подсказки сохранена.

Создано встроенным imagegen с `pip-sheet.png` как референсом. Общая инструкция: сохранить лицо, пропорции, акварельную фактуру, оливковую панаму, красный платок и рюкзак; прозрачный фон, без текста, поля 6%. Индивидуальные задания: показать лапой вправо от зрителя без зеркального отражения экипировки; удивлённо поднять брови с лапой у подбородка; три портрета по грудь — улыбка, смущённая улыбка без слёз, радостный восторг. Полный набор и SHA256 — в `data/graphics-manifest.json`.

## Партия 1 — отдельные производственные файлы

По списку `docs/GRAPHICS_PLAN.md` добавлены 8 отдельных PNG: опорный лист 2048×1024, четыре базовые позы и oops/spyglass/cheer по 1024×1024. Они созданы с утверждённым листом как референсом; это отдельные рендеры, не пиксельная нарезка старого листа. Производственные PNG приведены к требуемым размерам без изменения пропорций, альфа-канал сохранён. Полный план содержит 76 файлов, статусы и SHA находятся в `data/graphics-manifest.json`.

Текущий рендер базового костюма использует отдельные картинки: ошибка → oops, три ошибки/телескоп → spyglass, правильный ответ → yes, завершение → cheer. На главной добавлена ссылка `/graphics/` с просмотром на светлом и бирюзовом фоне. Опорный лист и map/point-left доступны там для проверки, а не спрятаны в репозитории. Все новые картинки ждут визуальной проверки пользователем на телефоне; создание файла не означает дополнительного редакторского approval. Следующая партия: остальные MVP-эмоции/головы и костюмы, затем штампы/паспорт/маршрут. Остальной текст ниже описывает первоначальную интеграцию и сохранён для происхождения ресурса.

24 октября 2026 пользователь утвердил новый акварельный дизайн Пипа и попросил вставить в проект. Исходное изображение `assets/pip/pip-poses-v1.png` — прозрачный RGBA sprite sheet 1355×1161, четыре позы в сетке 2×2. Оно сохраняется целиком; квадранты отображаются CSS, без перерисовки персонажа кодом.

Слева сверху — приветствие, справа сверху — успех, слева снизу — карта/подсказка, справа снизу — поддержка после ошибки. Базовый костюм `hat` использует новый дизайн во всех существующих местах Пипа. Остальные пять разблокируемых костюмов сохраняют прежнюю SVG-отрисовку до подготовки отдельных утверждённых иллюстраций. XP, сохранённый выбор костюма, подсказки и правила зачёта не меняются.

Изображение включено в release allowlist и offline shell. Версия cache обновлена. Этот контроллер находится в действующем прототипе; это не перенос старого маршрута 1+6 в новую основную концепцию. Ресурс можно переиспользовать в новом движке.

Ручная проверка: открыть главную, игру и завершение — виден новый Пип без фрагментов соседних поз. Правильный выбор показывает радость, ошибка — поддержку, предложение подсказки — позу с картой. Проверить телескоп по нажатию, выбор прежних разблокированных костюмов и запуск без сети. Mobbin подключён пользователем для будущей работы над интерфейсом, для замены Пипа не использовался.
