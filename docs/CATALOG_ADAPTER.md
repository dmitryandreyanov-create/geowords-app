# Адаптер реального каталога: сначала Level 1

`tools/catalog-adapter.mjs` компилирует проверенные данные в существующий `engine/curriculum.js`. Он не вводит отдельный генератор L1, не подключён к игре и не включён в Pages. Настоящий L1 сейчас **blocked**, `curriculum: null`; ни один pending-источник не утверждён.

## Три независимых входа

1. Полученные назначения букв `review-assignments.json`, совместимые с экспортом v1/v2 единого редактора. Все назначения сохранены; 69 неоднозначных букв повторно назначать не требуется. Для выпуска нужны индивидуальные подтверждения всех подсказок. v1 не создаёт их автоматически.
2. Отдельный экспорт географии единого редактора: полная география каждого glyph, оба канала стрелки, SHA карты и точная геометрия. Назначенное слово не доказывает географию.
3. Редакторский manifest: реальные факты/оговорки, учебный порядок, места, формулировки/запросы, словарь, набор видимых объектов карты, владелец каждого якоря и явный выпуск L1. Кандидаты не копируются в утверждённые поля: шаблон содержит null.

Шаблон перечисляет 296 записей: 1 выпуск, 1 курс, 21 место, 23 факта L1, 63 дескриптора, 60 слов, 10 шагов, 10 map scopes, 10 авторских заданий, 97 владельцев якорей. Это не 296 новых географических назначений: назначение ответа уже получено, владение якорем нужно для общей модели и квоты фокуса. В едином редакторе доступны проверка 23 фактов/10 порядков шагов и панель 63 формулировок/60 слов; остальные разделы manifest пока без собственного интерфейса. Экспорты назначения и географии используются отдельно.

Каждая запись имеет `sourceSha256`, `status`, `decision`, `evidence`. Подтверждение хранит `reviewedBy`, `sourceSha256` и `decisionSha256` (канонический SHA-256 решения, API `fingerprint`). Изменение источника или решения делает подтверждение устаревшим. SHA — связь с проверенной версией, **не цифровая подпись или доказательство личности автора**. CLI не имеет операции автоматического утверждения. Заполнять утверждения нужно только после содержательной проверки, не ради прохождения теста.

У владельца якоря fingerprint включает также актуальный экспорт географии: изменение physical/target аннулирует старое редакторское подтверждение даже при прежней геометрии. После географической проверки создать соответствующий шаблон можно командой `node tools/catalog-adapter.mjs --template --spatial /tmp/geowords-spatial-reviewed.json > /tmp/geowords-editorial-template-after-geography.json`. Это создаёт пустые решения, а не подтверждения.

## Что проверяет адаптер

- Полный scope исходников, отсутствие лишних/повторных/пропущенных решений; отдельная блокировка null, pending и stale evidence. Неверный вход не даёт частично утверждённый Curriculum.
- Независимое разрешение каждой авторской подсказки среди **всех букв её карты** с реально изученными фактами/местами на этом шаге; результат должен быть unique и совпадать с полученным назначением. Нельзя одобрить неоднозначную подсказку выбранным ответом.
- Оговорки источника должны сохраняться и изучаться вместе с соответствующими фактами. Порядок открытия задаётся явно; optional/candidate не становятся знаниями ребёнка.
- Принадлежность владельца якоря проверяется по утверждённой географии, а не candidateTarget или букве. Видимые объекты карты задаются явно, не выводятся из выбранного ответа. Фокус шага допускает несколько объектов; пустой список возможен только как явное проверенное решение. Обязательный новый объект на каждом шаге не выдумывается.
- Девять заданий L1 используют один bitmap, но имеют разные glyph scopes. Runtime map ID — `puzzleId + '-map'`; asset, SHA, пропорции, координаты и стрелки сохраняются. Evidence map ID проецируется после проверки исходного scope; исходное свидетельство хранится в `sourceEvidence`. Буквы разных заданий не объединяются по пути картинки.
- Существующий валидатор Curriculum проверяет 1+6, семь разных слов, запрет 62 авторских ответов, изучаемые зависимости и накопление объектов, включая вводимые учебными фактами.
- После всех редакторских проверок общий генератор должен действительно создать шесть практик на каждом шаге; каждая перепроверяется и проходит обычный зачёт. При нехватке безопасной геометрии — `GEOMETRY_NOT_VERIFIED`, без уменьшения 1+6 или квоты фокуса. Это ограниченный технический прогон, не доказательство бесконечного разнообразия. Его прогресс не сохраняется.
- Новые определения сохраняют происхождение/исходное определение; из них не открываются knownFacts.

## Воспроизведение

Отчёт по текущим pending-источникам (без записи): `node tools/catalog-adapter.mjs`.

Получить пустой шаблон, не перезаписывая существующий файл: `node tools/catalog-adapter.mjs --template > /tmp/geowords-editorial-template.json`.

Проверить три реально проверенных экспорта: `node tools/catalog-adapter.mjs --editorial /tmp/geowords-editorial-reviewed.json --spatial /tmp/geowords-spatial-reviewed.json --assignments /tmp/geowords-assignments-reviewed.json --require-ready`.

`--require-ready` возвращает ненулевой exit code при блокировке; JSON содержит точный `code/key/detail` и `curriculum: null`. Даже результат `ready: true` не публикует контент и не меняет приложение. Шаблон/отчёт можно создавать локально; коммитить реальные подтверждения следует после проверки автора. Source JSON не перезаписываются.

Тест: `node scripts/validate-catalog-adapter.mjs`. Реальные источники проверяются только на сохранение pending и назначений. Положительная компиляция, 1+6, stale/null/ambiguous/future/spoiler/geometry сценарии используют **отдельный синтетический курс**, его approvals не сохраняются в авторских данных.

Экспорт новой панели подключается отдельно: `node tools/catalog-adapter.mjs --learning /tmp/geowords-l1-learning-review.json --require-ready`. Он заменяет только 33 проверяемые записи фактов/шагов в пустом или совместимом общем manifest. Конфликт с уже утверждённой записью общего manifest отклоняется; места, словарь, запросы, карты и выпуск не утверждаются. Можно комбинировать `--learning`, `--editorial`, `--spatial` и `--assignments`. Инструкция панели — `docs/LEARNING_REVIEW.md`.

Подсказки и определения принимаются через `--content /tmp/geowords-l1-content-review.json` (можно вместе с остальными опциями). Этот слой содержит только 123 descriptor/word записи, требует отдельных смысловых/педагогических отметок и не разрешает географию, порядок фактов или выпуск. Инструкция — `docs/CONTENT_REVIEW.md`.

## Ревью checkpoint df6a587..9b7f1bd

В адресном ревью выявлены и исправлены два пробела:

- Явный общий `not_for_live_use` блокировал генерацию, но разрешал другие учебные действия при approved-курсах. Теперь такой статус блокирует availability/acknowledge/complete и восстановление знаний. Старые тестовые/legacy-каталоги без верхнего status сохраняют прежний контракт; генерация требует явный approved, а адаптер всегда задаёт статус.
- Накопление объектов карты учитывало только `introducedPlaces`. Теперь учитываются также объекты, вводимые `learnBefore/unlockAfter` текущего и предыдущих шагов курса. Регрессия проверяет пропажу объекта, введённого только фактом.

Это внутреннее техническое ревью Codex. Независимое ревью Claude этого checkpoint не подтверждено. L2-адаптер, остальные разделы редакторского manifest, подключение полного маршрута, миграция прогресса и iPhone/PWA тест остаются следующими этапами. PR #8 не мержить без согласования.
