# GeoWords: единое ядро и генератор заданий (v0.4 pilot)

## Назначение

Одна модель задания для двух источников:

- **Authored / Mountains** — 11 авторских геовордов из существующей тетради. Их растровые карты, координаты, тексты и прогресс сохранены без изменений.
- **Generated / Rivers** — автоматическая сборка новых геовордов из словаря, базовой карты и географических объектов, накопленных к текущему шагу.

Пользователь выбирает Mountains или Rivers на домашнем экране. Для Rivers требуется решить **7 разных слов**, после чего автоматически вводится новый географический объект. Ошибки при выборе букв не обнуляют прогресс; повторное решение той же комбинации не повышает счётчик.

## Файлы и зоны ответственности

| Файл | Назначение |
|---|---|
| `engine/geowords.js` | Чистая модель: адаптация авторских заданий, общий словарь, детерминированная генерация, прогресс и запрет повторного зачёта |
| `data/levels.js` | Исходные 11 авторских Mountains; **не переписывать под генерацию** |
| `data/dictionary.js` | Черновой тематический EN-словарь терминов Rivers — 21 слово с определением; требует редакторского утверждения автором |
| `data/courses.js` | Сценарий Rivers: один новый объект за шаг, точки-якоря, контуры рек, список слов по шагам |
| `assets/world-rivers-base.svg` | Карта мира **без букв** и без встроенных учебных рек |
| `app.js` | Отображение и управление: один игрок для авторских и генерируемых заданий |
| `scripts/validate-generator.mjs` | Проверка 21 задания, 7/7, отсутствия повтора, координат и прогресса |

## Как работает генерация

1. Берётся текущий шаг и список **всех уже изученных** объектов.
2. По словарному ID берётся слово и его определение. Если слова нет — ошибка, а не произвольная выдумка.
3. Обязательные якоря изученных объектов дополняются точками океанов и континентов.
4. Точки подбираются с минимальным расстоянием 34 px на ширине карты 322 px; буквы и порядок подсказок определяются воспроизводимым seed.
5. Выход — стандартный объект задания с полями `id, source, title, answer, map, markers, clues, definition` и дополнительным массивом `features` для отрисовки введённых рек.
6. Ответ проверяет существующий движок — отдельной логики угадывания для Rivers нет.

Важно: генерация создаёт множество вариантов **из конечного редакторского словаря**. Это не бесконечный набор новых географических терминов. После завершения курса доступна неограниченная практика с новыми вариантами расположения букв.

## Учебная последовательность пилота

| Шаг | Новая река | Ранее введённые объекты | Цель |
|---|---|---|---|
| 1 | Нил | Континенты, океаны | 7 различных слов |
| 2 | Амазонка | Нил + континенты/океаны | 7 различных слов |
| 3 | Янцзы | Нил + Амазонка + континенты/океаны | 7 различных слов |

После 7-го слова на шаге запускается короткое поздравление и **автоматически** показываются факты о новой реке (затем ребёнок нажимает «I'm ready» для начала игры). Все ранее добавленные реки остаются нарисованными.

На последнем шаге после 7/7 доступен режим повторения, без ложного увеличения зачтённых результатов.

Прогресс хранится отдельно по ключу `geowords_rivers_progress_v1` в `localStorage`, с безопасным fallback в оперативную память. Старые ключи `geowords_completed_*` для Mountains не меняются.

## Добавление новой темы

1. Нарисовать чистую базовую карту темы без встроенных букв.
2. Описать объект и его геометрию/точку привязки в `data/courses.js`.
3. Добавить утверждённые автором слова с определениями в `data/dictionary.js`.
4. В каждом шаге задать семь словарных ID (или впоследствии заменить это правило на автоматическую ротацию).
5. Выполнить `node scripts/validate-generator.mjs` и ручной тест телефона.

Формат допускает английский и русский контент, но **локализация не реализована** в этой версии. Полные переводные фразы нужно хранить в данных, не собирать русскую грамматику по шаблонам.

## Проверка перед merge

```sh
node --check app.js && node --check engine/geowords.js && node scripts/validate-levels.mjs && node scripts/validate-generator.mjs
```

Ручной сценарий: проверить первый и седьмой геоворд Нила; после 7/7 должна появиться Амазонка без ручного выбора шага. Повторение слова не прибавляет очко. На Амазонке остаётся Нил; на Янцзы остаются обе предыдущие реки. Затем открыть Mountains и убедиться, что все 11 исходных заданий и медали доступны, размеры карт не изменились. Дополнительно проверить зум/drag и 360px viewport.

### Перед широкой публикацией

- Утвердить географические факты, определения и порядок слов с автором.
- Проверить на реальном iPhone читаемость чистой карты, рек и букв.
- Уточнить картографический источник/лицензирование при коммерческом использовании.
- Позже добавить разные типы подсказок и более широкий словарь: на этой стадии генерируются размещения букв по фиксированным корректным географическим указаниям.
