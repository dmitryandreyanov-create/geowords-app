# Практика Level 1: план словаря, не готовые задания

Подготовлено по шесть слов-кандидатов для десяти исходных шагов L1. На каждом шаге сохраняется утверждённое правило: авторский геоворд первым, затем шесть разных практических, переход после 7/7 завершённых слов; исправленные ошибки не отменяют зачёт.

Это **предложение Codex, не авторский материал**. Ни подбор, ни определения, ни темы ещё не утверждены преподавателем. Слова не подключены к игре и не считаются сгенерированными заданиями. Геометрическая осуществимость не проверена: генератору ещё нужны полностью проверенные якоря, учебные факты и семантические запросы. Зелёный CI не подтверждает пригодность этих слов для ребёнка.

## Единый словарь

`lexicon-draft.json` объединяет 18 уже существующих черновых слов пилота Rivers и 59 новых предложений, всего 77 записей. HABITAT переиспользует существующий ID и определение; второе определение для того же слова не создаётся. Все записи `editorial_pending`, происхождение явное. У новых слов оценка угадываемости пока null, её нельзя считать «medium» автоматически.

`l1-practice-vocabulary-proposals.json` — исходный редакторский подбор; `build_lexicon_draft.mjs` собирает общий черновик и отдельные `practicePlans`. Он не меняет игровой `data/dictionary.js`, runtime `wordIds` или пустой утверждённый Lexicon основного Curriculum. Позднее утверждённые записи должны войти в общий Lexicon, а не образовать отдельный генератор/словарь для L1.

Все 60 кандидатов различны в этом конкретном плане, но это не новое правило зачёта между шагами. Ни один не совпадает ни с одним из 62 авторских ответов всех тетрадей. Поэтому LONGITUDE, ARCHIPELAGO и ESCARPMENT в план не включены: они встретятся как авторские слова позднее. Это проверка спойлеров по ответам, а не доказательство отсутствия всех смысловых пересечений; семейства понятий ещё требуют редакторской проверки.

Темы служат подсказкой редактору. Они не утверждают момент открытия фактов, порядок новой лексики или педагогическую сложность. Определение итогового слова **не** превращается автоматически в `knownFacts`; `introducedFacts:null`. Запрещено использовать факт из предложенного определения в географической подсказке, пока факт не введён утверждённым учебным экраном.

## Что дальше

1. Проверить определения, возрастную пригодность, угадываемость, семейства понятий и распределение по шагам. Синонимы WATERSHED/CATCHMENT, общие слова LOCATOR/REFERENCE и более сложные AZIMUTH/ABYSSAL/VOLCANISM — особенно важные решения для редактора; не считать их утверждёнными.
2. Подтвердить реальные географические свойства и proposed-факты L1. Только после этого проверить выбор достаточного числа различных, однозначно описываемых якорей, расстояния на телефоне, стрелки и квоту нового объекта там, где он вводится.
3. Генерировать реальные варианты единым ядром, а не новым генератором для L1. Проверить шесть разных практических слов, отсутствие авторского ответа, 7/7 и накопление изученных объектов/фактов. Сейчас `generatedPuzzles:[]` у всех десяти планов.
4. Утверждённый каталог, интеграция Curriculum, iPhone/PWA и повторное адресное ревью Claude до merge.

Проверка одной строкой: `node tools/build_lexicon_draft.mjs --check && node scripts/validate-lexicon-draft.mjs`.
