Карта

Выберите подсказку справа, затем соответствующую букву на карте. Обведённые жёлтым буквы — допустимые кандидаты. Для каждого задания одна буква используется один раз.

Исходные факты из PDF (требуют редакторской проверки)

Подсказки

Экспорт сохраняет назначения и отдельные подтверждения географии. Проверьте также буквы, сопоставленные автоматически. Разметка автоматически сохраняется в этом браузере, если доступно локальное хранилище. Периодически экспортируйте JSON как резервную копию. Незавершённые соответствия остаются пустыми.

География букв · Level 1

Это отдельная проверка всех букв, не повторное назначение ответов. Выберите букву независимо от выбранной подсказки. Укажите все применимые свойства по исходной карте, включая вложенные объекты (например, Asia и Eurasia). В списках можно выбрать несколько пунктов; на Windows — Ctrl + щелчок. Пустой список означает отсутствие свойства только после подтверждения полноты.

Независимый черновой отчёт о подсказках

Отчёт проверяет все буквы задания, но использует ещё не утверждённые запросы и предполагаемые факты. Он не подтверждает уроки, не ставит старые отметки географии и не публикует задания.

Географическая панель пока доступна только для Level 1. Назначения и проверка подсказок Level 2 работают как раньше.
