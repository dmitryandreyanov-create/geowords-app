# GeoWords — визуальная разметка 20 заданий L1/L2

Этот редактор нужен **только для проверки авторского импорта**. Он не входит в текущую игру, не меняет PWA и не создаёт готовых к публикации заданий.

## Как открыть

В корне локальной копии ветки `gpt/unified-geowords-engine` запусти **одной строкой**:

```sh
python3 -m http.server 8080
```

Затем открой в браузере `http://localhost:8080/tools/review-import.html`. Python-сервер нужен лишь для доступа к локальным JSON и WebP (обычный `file://` часто блокирует `fetch`). Интернет и отдельный бэкенд не нужны.

## Как проверять

1. Слева выбери оригинальный геоворд, начиная с `L1-01`. Карту и текст подсказок берём непосредственно из PDF.
2. Справа выбери подсказку. На карте жёлтым обведены **только буквы того же символа**, из которых можно выбрать. Сначала физически найди нужную букву по географии и, при необходимости, по оригинальной PDF-стрелке.
3. Нажми букву на карте. Выбор сохраняется в открытой странице; одна буква не может быть назначена двум подсказкам.
4. Каждые несколько заданий нажимай **«Экспорт разметки JSON»**. Если пришлось вернуться позднее, импортируй сохранённый файл через **«Импорт сохранённой разметки»**.
5. После проверки загрузи файл `geowords-l1-l2-reviewed-assignments.json` в чат разработчика или добавь его содержимое в `data/import-staging/review-assignments.json` в ветке. Сам редактор не изменяет файлов на диске автоматически.

При первом открытии **118 из 187** соответствий уже однозначны по символам. Остальные **69** не были назначены автоматически, чтобы не создавать ошибочных учебных заданий. Даже первые 118 требуют географического QA; зелёный цвет означает техническое совпадение, а не редакторское утверждение.

## Обязательные ограничения

- Имеющиеся PDF-стрелки на промежуточной карте не отображены; проверяй исходную страницу при любой букве с указателем.
- Раздел `factsExtract` показывает сырой текст, в нём могут быть колонтитулы и разрывы строк. Не копируй его автоматически в `knownFacts`.
- Файл решения содержит только выбранные пары «позиция подсказки → ID маркера». Это не подтверждение географической семантики и не готовый Curriculum.
- `node scripts/validate-import-review.mjs` проверяет, что данные не повторяют буквы и не ссылаются на неподходящие символы. Он не может самостоятельно доказать правильность расположения на глобусе.
- До полного утверждения держи `status: human_review_pending` и не подключай `data/import-staging` в `index.html`.
